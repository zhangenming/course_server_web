## 目标
- 保留现有“管理员登录”不变，在同一页面新增“学员登录/注册”切换通道。
- 学员登录：仅手机号；前端校验与防重复提交；HTTPS 传输；脱敏展示。
- 学员注册：用户名、不可编辑的默认密码、角色下拉、性别单选、手机号；字段校验、分组布局、HTTPS、防重复提交与脱敏展示。

## 接口与调用
- 学员登录：`commons/login_alt`；请求体：`{ username: null, phone }`。
- 学员注册：`api/v1/users/`；请求体：`{ username, password: 'admin123', role, gender, phone }`。
- 统一使用已有请求封装：`apiJson` 与 `apiFetch`（src/utils/request.ts:1–93, 100–121）。开发环境已启用 HTTPS（vite.config.ts:18），通过 `'/vite'` 代理发起 HTTPS 请求。

## 前端实现
- 切换选项：在登录卡片头部新增切换控件（`管理员登录 | 学员登录/注册`）。默认停留“管理员登录”，选择“学员登录/注册”后展示学员区域。
- 学员区域采用二级切换：`登录 | 注册` 两个子页，保持现有 UI 视觉风格（沿用 `login.vue` 现有样式类）。

### 学员登录表单
- 字段：`phone`（`type='tel'`，`inputmode='numeric'`，`autocomplete='tel'`）。
- 校验：不能为空、格式 `^1[3-9]\d{9}$`；失焦与提交前均校验。
- 提交：`apiJson('commons/login_alt', { method: 'POST', body: { username: null, phone } })`；成功后写入 `token` 与刷新页面（参照管理员登录流程，src/login.vue:73–106）。
- 防重复提交：`studentLoginLoading` guard + 禁用按钮 + loading 态。
- 脱敏：在提示文案或回显中使用 `maskPhone(phone)`（如 `158****2175`），不在存储/日志中保留明文。

### 学员注册表单
- 字段：
  - `username`（文本）
  - `password`（固定值 `admin123`，禁用输入）
  - `role`（下拉，默认 `student`，可选 `student/teacher/admin`）
  - `gender`（单选，默认 `男`，可选 `男/女`）
  - `phone`（文本，同登录校验）
- 校验：
  - `username`：3–50 字符
  - `password`：固定不可编辑（仅展示，必填值由代码写入）
  - `role`：必选
  - `gender`：必选
  - `phone`：格式校验
- 布局：分组/分步（单卡片内分组标题），对齐现有 `login.vue` 的表单风格与响应式。
- 提交：`apiJson('api/v1/users/', { method: 'POST', body: { username, password: 'admin123', role, gender, phone } })`；成功后可提示“创建成功”，并引导去学员登录。
- 防重复提交：`studentRegisterLoading` guard + 禁用按钮 + loading 态。
- 脱敏：提示/回显使用 `maskPhone(phone)`。

## 安全与传输
- HTTPS：开发环境已启用（vite.config.ts:18）；在提交函数中校验 `location.protocol === 'https:'`，生产环境若非 HTTPS 则阻止提交并提示。
- 敏感信息：
  - 输入仅用于请求体发送；不写入 `localStorage`（除后端返回 `token`）。
  - 提示文案与 UI 回显采用脱敏号码。
- 防重复提交：通过 loading 状态与按钮禁用实现。

## 代码改动范围

- 本地通过 HTTPS dev server 打开登录页，依次验证：

  - 学员登录：错误格式拦截、正确格式请求成功写入 `token` 并刷新。
  - 学员注册：校验提示、成功返回与引导登录。
- 移动端与桌面端：检查响应式布局与触控键盘（`tel`）。
