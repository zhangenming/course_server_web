## 目标
- 将注册表单里的 `select` 下拉框样式升级为现代风格，保持现有交互与数据（`v-model=regRole` 值仍为 `student`/`teacher`）。
- 适配浅色/深色模式与超高分辨率（含 2160×3840），保留键盘可访问性与移动端体验。

## 改造方案（优先：CSS 原生选择框美化）
- 保持原生 `<select>`，通过 CSS 实现现代化外观；不引入新依赖，风险最小。
- 统一风格：圆角、细边框、柔和阴影、绿色主题焦点态、悬停反馈、禁用态、错误态。
- 自定义下拉箭头：使用内联 SVG Data URI 作为背景图，不影响可访问性。

## 具体改动
### 模板小调整
- 在 `src/login.vue` 注册表单角色处将现有结构包一层容器，便于绘制箭头：
```vue
<div class="input-wrapper select-wrapper">
  <select v-model="regRole" class="form-input modern-select" @blur="validateRegRole">
    <option value="student">学生</option>
    <option value="teacher">老师</option>
  </select>
</div>
```

## 可选方案（Element Plus 组件）
- 若希望统一 UI 组件风格，可将原生 `<select>` 替换为 `el-select`：
```vue
<el-select v-model="regRole" placeholder="请选择" class="modern-select" size="large" @change="validateRegRole" filterable clearable>
  <el-option label="学生" value="student" />
  <el-option label="老师" value="teacher" />
</el-select>
```
- 优点：交互更丰富、风格与其他 `el-button` 保持一致；缺点：与原生选择框相比体积更大、需要调整事件从 `@blur` 改为 `@change`。

## 可访问性与交互
- 保留键盘导航（Tab/上下箭头），焦点可视化明确（绿色 focus ring）。
- 颜色对比度符合 WCAG，深色模式同步适配。
